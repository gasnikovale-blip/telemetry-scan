# RaceChrono Telemetry Analyzer

Программа для анализа гоночной телеметрии, экспортированной из приложения RaceChrono, с расчетом физико-динамических параметров автомобиля (мощность, крутящий момент, G-силы) и их визуализацией.

Есть два режима: **графический интерфейс** (основной, для Windows и Linux) и **консольный** (для автоматизации и любителей командной строки). Оба работают с одной и той же библиотекой расчетов и создают одинаковые PDF-отчеты.

---

## 🖼 Графический интерфейс — основной режим

### Запуск

1. Установите **Python 3.8** или новее с [python.org](https://www.python.org/downloads/) (при установке отметьте галочку «Add Python to PATH»).
2. Установите зависимости: двойной клик по файлу **`install_requirements.bat`** (или команда `pip install -r requirements.txt`).
3. Запустите программу: двойной клик по **`analyzer.bat`** (или `python telemetry_app.py`).

### Как проанализировать заезд

1. **Выберите файл лога** — кнопка «Обзор...». Это CSV-файл, экспортированный из RaceChrono (удобно хранить их в папке `data/`).
2. **Выберите профиль автомобиля** — выпадающий список заполняется автоматически из папки `cars/`. После выбора профиля все поля параметров заполнятся его значениями и останутся редактируемыми (подробнее — в разделе [Профили автомобилей](#-профили-автомобилей-папка-cars)).
3. **Отметьте круги** — после выбора файла появится таблица кругов:
   * колонка **«Время»** — время каждого круга;
   * колонка **«К лучшему»** — отставание от самого быстрого круга (он выделен зеленым, обрывки кругов в начале/конце выезда помечены прочерком);
   * клик по строке включает/выключает круг — неотмеченные круги будут скрыты на графиках;
   * сортировка по любому столбцу — кликом по его заголовку.
4. **Заполните данные заезда** (пилот, трасса, погода) — они попадут на титульный лист PDF-отчета.
5. **При желании задайте имя отчета** — поле «Имя отчета»: файл сохранится как `reports/<имя>.pdf`. Пустое поле — автоматическое имя с датой и временем: `reports/Отчет_<имя файла>_20260927_143510.pdf`, поэтому повторные анализы не перезаписывают предыдущие отчеты.
6. Нажмите **«Анализировать»**.

### Что вы получите

* **PDF-отчет** в папке `reports/` — полный путь покажет строка состояния внизу окна.
* **Пять интерактивных окон с графиками** (скорость, ускорения, G-G диаграмма, мощность, момент):
  * приближайте отдельные участки — лупа или выделение рамкой на панели инструментов окна;
  * сравнивайте круги — клик по линии легенды скрывает/показывает круг;
  * наводите курсор на график, чтобы видеть точные значения в точке.

  Статичный PDF этого не умеет, поэтому окна сделаны такими же, как в консольном режиме: детальный разбор поворота или участка разгона удобнее вести в интерактиве, а PDF — для отправки и печати. Окна можно не закрывать: следующий анализ откроет новые, не тронув старые.

По умолчанию заложены параметры **VW Polo Sedan 1.6 (2017 г.в., МКПП)**; для своей машины создайте файл-профиль в `cars/` (см. [Профили автомобилей](#-профили-автомобилей-папка-cars)).

## ⌨️ Консольный режим

Базовый синтаксис команды запуска:
```bash
python telemetry_analyzer.py <путь_к_файлу.csv> [необязательные аргументы]
```
CSV-файлы телеметрии по умолчанию лежат в папке `data/`.

В Windows файл можно просто **перетащить на `analyzer_cli.bat`** — откроется консоль, выполнится анализ стандартными параметрами, в конце будет пауза, чтобы прочитать результат.

### Режимы запуска (Примеры)

**1. Стандартный запуск (для VW Polo Sedan)**
Показывает все найденные в логе круги. Используются стандартные параметры VW Polo. На графиках будет отображена только мощность двигателя.
```bash
python telemetry_analyzer.py data/session_20260718_122333_autodrom_gai_laps3-4_v3.csv
```

**2. Анализ конкретных кругов**
Если вы хотите сравнить только 2-й и 3-й круги, используйте аргумент `--laps`. Остальные круги будут скрыты.
```bash
python telemetry_analyzer.py data/session.csv --laps 2 3
```

**3. Расчет момента на коленчатом валу двигателя**
Для появления 5-го графика (Момент двигателя, Нм) скрипту нужно знать передаточное число передачи, на которой вы ехали большую часть круга. 
Для VW Polo 1.6 на 3-й передаче (1.229 КПП * 4.064 Главная пара ≈ 5.0):
```bash
python telemetry_analyzer.py data/session.csv --gear_ratio 5.0
```
Проще использовать профиль автомобиля — в `cars/vw_polo_sedan_16.ini` это значение уже указано:
```bash
python telemetry_analyzer.py data/session.csv --car cars/vw_polo_sedan_16.ini
```

**4. Указание данных заезда (пилот, трасса, погода)**
Вы можете добавить информацию о заезде, которая будет выведена на первую страницу PDF-отчета.
```bash
python telemetry_analyzer.py data/session.csv --driver "Алексей" --track "Нижегородское кольцо" --weather "Дождь"
```

**5. Настройка сглаживания графиков**
Если графики мощности и момента кажутся вам слишком зашумленными (или наоборот, слишком сглаженными), вы можете изменить окно сглаживания в секундах. По умолчанию используется 0.8 секунды.
```bash
python telemetry_analyzer.py data/session.csv --gear_ratio 5.0 --smooth_time 1.5
```

**6. Переопределение отдельного параметра из профиля**
Если указан и `--car`, и отдельный флаг (например `--mass`), приоритет у флага. Так можно разово поехать с пассажиром, не редактируя файл профиля:
```bash
python telemetry_analyzer.py data/session.csv --car cars/vw_polo_sedan_16.ini --mass 1400
```

**7. Свое имя PDF-отчета**
```bash
python telemetry_analyzer.py data/session.csv --report "Выезд 27.09"
```
Отчет сохранится как `reports/Выезд 27.09.pdf`. Символы, запрещенные в именах файлов Windows (`\ / : * ? " < > |`), заменяются на `_`; суффикс `.pdf` добавляется автоматически. Без `--report` используется имя с датой и временем: `reports/Отчет_<имя файла>_20260927_143510.pdf` — то же самое, что пустое поле «Имя отчета» в GUI.

После расчета откроются интерактивные окна графиков; консольное окно можно закрыть после их появления (окна графиков при этом остаются).

## 📋 Что делает программа (техническое задание)

Программа читает специфический текстовый формат RaceChrono (с разделителями `|` и многоуровневым заголовком), автоматически очищает данные от шума датчиков и строит интерактивные графики для анализа кругов на треке.

**Основные функции:**
1. **Парсинг лога:** Автоматическое определение структуры файла, наименование колонок, обработка дубликатов заголовков.
2. **Автоопределение частоты датчиков:** Скрипт анализирует временные метки (`timestamp`) и самостоятельно вычисляет частоту обновления данных (Гц).
3. **Умное сглаживание:** На основе вычисленной частоты скрипт рассчитывает размер окна фильтрации в точках, чтобы сглаживание всегда занимало заданное время в секундах. Используется двойная фильтрация: медианный фильтр (вырезает выбросы от кочек) + скользящее среднее.
4. **Нормализация кругов:** Расчет дистанции от начала круга (сброс в 0 метров) для наложения разных кругов друг на друга.
5. **Расчет физики автомобиля:** 
   * Учет сил инерции, аэродинамического сопротивления и сопротивления качению шин.
   * Расчет мощности на колесах и мощности двигателя (в л.с.).
   * Расчет момента на колесах и коленчатом валу двигателя (в Нм).
6. **Визуализация (5 графиков):**
   * Скорость от дистанции (км/ч).
   * Продольные и поперечные ускорения от дистанции (G).
   * Диаграмма G-G (Тяговый круг) — классический автоспортивный график использования сцепления шин.
   * Мощность двигателя от дистанции (л.с.).
   * Момент двигателя от дистанции (Нм).
7. **Интерактивность:** Возможность скрывать/показывать отдельные круги на графиках кликом по легенде.
8. **Генерация PDF-отчета:** Автоматическое создание документа со всеми графиками, временами кругов, параметрами заезда (пилот, трасса, погода) и расчетными данными. В отчет встроено предупреждение о корректности расчета момента/мощности.

## 📁 Профили автомобилей (папка cars/)

Вместо шести флагов (`--mass`, `--cd_a`, `--crr`, `--r_wheel`, `--efficiency`, `--gear_ratio`) параметры автомобиля можно хранить в файле и выбирать одним аргументом `--car`.

### Как создать профиль своего автомобиля

1. Скопируйте шаблон `cars/_template.ini` в той же папке.
2. Переименуйте, например: `cars/lada_granta.ini` (имя файла — без пробелов, путь к нему передается в `--car`).
3. Откройте файл в любом текстовом редакторе и заполните значения.

Файл — в формате INI, кодировка **UTF-8**. Поддерживаются комментарии: строкой целиком или после значения через `;` или `#`. Имена ключей — в нижнем регистре.

Пример (`cars/vw_polo_sedan_16.ini`):
```ini
[car]
name = VW Polo Sedan 1.6 (2017, МКПП)
mass = 1250
cd_a = 0.65
crr = 0.012
r_wheel = 0.288
efficiency = 0.90
gear_ratio = 5.0   ; 3-я передача: 1.229 * 4.064; 0 = момент не рассчитывается
```

### Ключи профиля

| Ключ | Обязателен | Описание |
| :--- | :--- | :--- |
| `name` | нет | Отображаемое имя (в GUI и PDF-отчете). Если не указано — имя файла. |
| `mass` | да | Масса автомобиля в кг (снаряженная + водитель + топливо). |
| `cd_a` | да | Аэродинамическое сопротивление (Cd * площадь лобового сечения, м²). |
| `crr` | да | Коэффициент сопротивления качению шин (0.010-0.015 для асфальта). |
| `r_wheel` | да | Радиус качения колеса в метрах. |
| `efficiency` | да | КПД трансмиссии долей: 0.90 = 90%. |
| `gear_ratio` | нет | Общее передаточное число (КПП * главная пара). **Если 0 или не указан** — график момента двигателя не строится. |

### Как указать профиль

В командной строке `--car` принимает **путь к .ini файлу** — относительный или абсолютный:
```bash
python telemetry_analyzer.py session.csv --car cars/vw_polo_sedan_16.ini
```

Если файл не найден, скрипт выведет подсказку со списком готовых профилей из папки `cars/`.

В графическом интерфейсе путь указывать не нужно: выпадающий список профилей заполняется автоматическим сканированием папки `cars/`.

### Приоритет параметров

```
явный флаг (--mass 1400)  >  профиль (--car ...)  >  встроенные значения VW Polo
```
Пример: `--car cars/vw_polo_sedan_16.ini --mass 1400` — возьмутся все параметры из профиля, кроме массы (1400 кг).

### Особенности выбора профиля в GUI

* Выбор профиля заполняет все поля значениями из файла; поля остаются редактируемыми.
* Ручное редактирование любого поля после выбора профиля сбрасывает выбор на «вручную (свои значения)» — чтобы отчет не приписывал измененным параметрам имя профиля.
* Кнопка «Обновить список профилей» перечитывает папку `cars/` — новые файлы подхватываются без перезапуска программы. Файлы, начинающиеся с `_` или `.` (шаблоны), в списке не отображаются.

## ⚠️ Важное замечание по расчету момента и мощности

**Графики момента и мощности двигателя корректны только на тех участках трассы, где вы действительно ехали на передаче, указанной в параметре `--gear_ratio`.** 

При переключении передач, движении накатом или торможении двигателем расчетные значения могут выдавать некорректные пиковые значения, так как скрипт не знает текущую передачу в каждый момент времени. Это предупреждение также дублируется на первой странице PDF-отчета.

## 📄 PDF-отчет

Все отчеты сохраняются в папку `reports/` проекта; папка создается при первом запуске. Имя файла задается в GUI (поле «Имя отчета») или аргументом `--report`; по умолчанию к имени добавляется штамп времени (`Отчет_<имя файла>_20260927_143510.pdf`), поэтому повторные анализы не перезаписывают предыдущие отчеты.

* **Страница 1:** Титульный лист с указанием исходного файла, даты, информации о заезде (трасса, пилот, погода), времен кругов, вычисленной частоты датчиков, введенных параметров автомобиля, предупреждения о корректности расчетов и методологии.
* **Страницы 2+:** Графики в высоком качестве с минимальными полями, готовые для отправки инженеру или распечатки.

## 🗂 Структура проекта

```
telemetry-scan/
├── analyzer.bat            # запуск GUI в Windows (двойной клик)
├── analyzer_cli.bat        # консольный анализ в Windows (можно перетащить CSV)
├── install_requirements.bat# установка зависимостей в Windows
├── telemetry_analyzer.py   # точка входа CLI (аргументы командной строки)
├── telemetry_app.py        # точка входа GUI (Tkinter)
├── car_profile.py          # загрузка профилей автомобилей (cars/*.ini)
├── lib/                    # библиотека анализа телеметрии
│   ├── config.py           #   AnalysisConfig — параметры анализа + валидация
│   ├── telemetry_io.py     #   чтение лога RaceChrono, круги, пиковые показатели
│   ├── physics.py          #   сглаживание, силы, мощность, момент
│   ├── plots.py            #   построение 5 графиков
│   ├── report.py           #   формирование PDF-отчета
│   ├── analysis.py         #   run_analysis — полный цикл
│   └── paths.py            #   пути к data/ и reports/, имена отчетов
├── cars/                   # профили автомобилей (.ini) + _template.ini
├── data/                   # CSV-файлы телеметрии RaceChrono
└── reports/                # сгенерированные PDF-отчеты
```

Логика анализа реализована один раз в `lib/` и используется обеими точками входа (GUI и CLI). Профили автомобилей не зависят от кода: добавить машину — значит добавить `.ini` файл в `cars/`.
